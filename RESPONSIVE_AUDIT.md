# RESPONSIVE_AUDIT — независимый аудит мобильной адаптивности веб-приложения MyBrev

Ветка `audit/responsive` (от main `b816ad2`). Только аудит: исправления не вносились, Flutter / продакшн-БД / деплой не затрагивались.
Скриншоты: `audit/responsive-screenshots/` (JPEG, ~187 файлов, отдельные ссылки ниже).

## 0. Как проводилась проверка и ограничения

- Приложение запущено локально (`vite --port 5199`) и **подключено к локальным Firebase-эмуляторам** (Firestore :8089, Auth :9099, проект `demo-responsive`). Продакшн не использовался (квота исчерпана). Для этого использовался временный неподключённый к коммиту хук в `src/plugins/firebase.js` (`connectFirestoreEmulator`/`connectAuthEmulator` за флагом `VITE_USE_EMULATOR`); после аудита он откачен.
- Эмулятор засеян из локальных снапшотов: `days`, `readings`, `liturgical*`, `invitatoriums`, `completoriums`, свежий снапшот от 2026-10-13 14:01 + статика (`prayers`, `prayerCategories`, `songs`, `compendium*`) от 2026-10-13 10:41. Мультинаборные чтения присутствуют (`massReadings`: 25.12 — ночью / на світанні / ўдзень; 15.08, 29.06, Пальмовая нядзеля, Пяцідзесятніца и т.д.). Для 24.12 в этих данных два варианта (Ранішняя / ў вігілію), а не три; у Пасхальнай вігіліі в данных нет набора «Св. Імша…» (только выбор цикла A/B/C) — это вопрос данных, не верстки.
- Для редактора создан локальный тестовый админ в Auth-эмуляторе + документ `admins/{uid}` (только эмулятор). Редактор чтений (`ParsedReadingEditor` / `MassReadingSetsEditor`) был достижим. `DayEditor` (/admin/day-editor) в этом проходе **не открывался**.
- Браузер: Playwright, **только Chromium (headless-shell 1228)**. WebKit/Safari в `~/Library/Caches/ms-playwright` отсутствует — реальный iOS Safari **не проверялся**. Реального устройства не было; экранная клавиатура и safe-area эмулированы (см. ниже).
- Объём: 957 загрузок «29 страниц × 9 ширин × 3 размера текста (0.7 / 1.0 / 1.8)» + тёмная тема на 320 и 390; ширины 320/360/375/390/412/430/768/1024/1440 (высоты 640–932 для телефонов). Все ключевые состояния просмотрены глазами по скриншотам. Дополнительно — автоматический поиск контента, обрезанного через `overflow:hidden` (обычный `scrollWidth > clientWidth` на документе такие дефекты **не видит**).

## 2. Детали по ключевым проблемам

### №1 Кнопки наборов Мессы (P1) — ранее заявленный дефект НЕ устранён
- Компонент: `src/components/readings/ReadingsView.vue` — `.set-choice__buttons` (≈:605), `.set-choice__button` (:612-616), медиа ≤600px (`.cycle-choice__button{flex:1 1 0}` :643-645).
- Условия: дата с тремя наборами (2026-12-25), ширина ≤ ~430 px, шрифт любой. Замер на 320: кнопки шириной 85 px при `scrollWidth` 101/127/104 px — текст выходит из кнопок на 16–42 px и наезжает на соседние. На 768 всё ок (одна строка).
- Скриншоты: `audit/responsive-screenshots/rd1225-320.jpg`, `rd1225-360.jpg`, `rd1225-390.jpg`, `rd1225-430.jpg`, `rd1225-f18-320.jpg` (при 180 % перекрытие сохраняется — подписи кнопок не масштабируются).
- Связано с №2/№3 только общим экраном. Две кнопки (15.08, 29.06, Пальмовая) умещаются на 320, но «Св. Імша ў вігілію» без запаса (`rd0815-320.jpg`, `rd0629-320.jpg`).

### №2 «Гэта слова Божае/Пана» (P1) — ранее заявленный дефект НЕ устранён
- `ParsedReadingCard.vue:432-436`; акклямация выводится вне `.section-text` (строки 52, 60, 138), поэтому не получает `calc(…*var(--font-size-multiplier))` (ср. :373, :384, :393, :401, :413).
- Замер `getComputedStyle().fontSize` = `16px` при множителях 0.7 и 1.8 на 320 и 390. Скриншот: `rd-acc-f18-320.jpg`, `rd-acc-f18-390.jpg`, `rd-acc-f7-320.jpg`.

### №3 Обрезка заголовка секции при большом шрифте (P1)
- Автопроверка «ребёнок шире обрезающего предка» нашла `.section-label` «Рэспансарыйны псальм» на 320 × 180 % на **всех** страницах чтений (`rd`, `rd1225`, `rd0629`, `rdPalm`, `rdVigil`). Страничного горизонтального скролла при этом нет — дефект скрыт `overflow:hidden` на `.parsed-reading` (:297-299), то есть пользователь просто видит обрезанное слово. Скриншот: `rd-acc-f18-320.jpg` (нижняя часть).

### №4 Диоцезии (P2) — ранее заявленный дефект НЕ устранён
- `Settings.vue:37` разметка, CSS `:219-221`, `:248-249`. Геометрия на 320: кнопки (x,y,w,h) `✓Мінска-Магілёўская` 31,586,87×51; `Гродзенская` 123,586,89×51; `Пінская` 218,586,71×51; `Віцебская` 31,642,258×36. Галочка `✓` (`.diocese-check`, :257) вставляется в поток и ломает перенос/высоту только у активной кнопки.
- Скриншоты: `settings-320.jpg`, `settings-390.jpg`, `settings-1024.jpg`, `settings-f18-320.jpg`, `dark-settings-390.jpg`.

### №5 Тень закрытого меню (P2)
- `NavigationDrawer.vue:338` `box-shadow:10px 0 32px var(--nav-shadow) !important`; замер: drawer `left:-320…0`, `visibility:visible`, `transform:translateX(-320px)`. Видно на каждом скриншоте слева (например `home-1440.jpg`, `home-320.jpg`).

## 3. Повторная проверка ранее найденных дефектов (раздел 3 задания)

**Верхние панели.** Выход за экран: нет (автопроверка bounding box на 957 загрузках, 0 нарушений). Столкновения меню / календаря / шрифта: нет на 320–1440 (`home-320`, `oras-320`, `laudes-320`, `rd1225-320`). Капсула «Літургія»: корректна (`rd1225-390.jpg`), выпадающий выбор часа открывается и подсвечивает текущий час (`hour-menu-320.jpg`; при высоте 640 список прокручивается, последняя строка «Камплета» обрезана краем — прокрутку внутри меню не проверял). Sticky-капсула часа не перекрывает основной текст, но текст проходит под плавающими кнопками (№7). Ambient UI / Gloria Glass сохраняется в светлой и тёмной теме.

**Литургические чтения.** Кнопки Мессы пересекаются — №1 (не устранено). Длинные заголовки («29 чэрвеня — урачыстасць святых Пятра і Паўла, апосталаў», «Унебаўзяцце Найсвяцейшай Панны Марыі») переносятся без обрезки (`rd0629-320.jpg`, `rd0815-320.jpg`). Масштаб «Гэта слова…» — №2 (не устранено). Горизонтальной прокрутки при большом шрифте на уровне страницы нет, но есть скрытая обрезка — №3.

**Настройки.** №4 (не устранено). Галочки/длинные названия: «Мінска-Магілёўская» ломает геометрию (неравная высота). Остальные отступы блоков ровные.

**Редактор чтений** (локальный тестовый админ, `/admin/reading-editor/feast-pentecost?date=2027-05-16`, `/25-12-naradzhenne-pana?set=night`, `/ordinary-w28-d3--1`). Пояснительный текст за экран не выходит; горизонтального overflow нет на 320/390/768. Поля ввода крупные (высота ≈55 px), метки не накладываются, кроме обрезанного длинного лейбла (№12). Экранная клавиатура эмулирована уменьшением viewport до 55 % высоты: сфокусированное поле остаётся в видимой области (`editor-keyboard-320.jpg`, замер bottom 332 < vh 352) — это **не** реальная клавиатура iOS/Android (visualViewport/`interactive-widget` не проверялись).

**Нижняя навигация.** Последние строки доступны: контент заканчивается выше навигации (`has-bottom-nav` padding 92 px, `layouts/simple/One.vue`; `bottom-rd1225-390.jpg`, `bottom-ordo-390.jpg`, `bottom-laudes-320.jpg`). Прямые `env(safe-area-inset-*)` (BackToTop `:21`, NextHourLink `:30`, MassSectionNav `:100`, compendium.css) эмулировать нельзя — проверены статически (используют корректное `calc(… + env())`). Плавающие стрелки читаемость не ломают, но пилюля просвечивает (№6). Кнопка «наверх» и нижняя навигация не перекрываются: на страницах чтений кнопка выше навигации (`bottom-rd1225-390.jpg`), на страницах часов навигации нет.

## 4. Увеличенный текст (минимум 70 % / 100 % / максимум 180 %)
- Страничного горизонтального overflow нет ни на одной из 29 страниц × 9 ширин × 3 размеров.
- Тело чтений, псалмодия, респонсории масштабируются согласованно; обрезки — №2, №3. На 320 × 180 % названия часа в капсуле (`Гадзіна чытанняў`) переходят на 2 строки, но кнопки остаются доступными (`lectionis-f18-320.jpg`).
- Элементы интерфейса (кнопки, настройки, списки главной) намеренно не масштабируются от множителя — только читаемый текст; предпросмотр в Настройках масштабируется.
- Масштаб Chromium text-zoom / системного «Крупного текста» ОС не проверялся (только собственный множитель приложения).

## 5. Светлая / тёмная тема
Читаемость, акценты литургических цветов (зелёный, красный, золотой, синий, фиолетовый), границы карточек и стекло выглядят единообразно (`dark-home-390.jpg`, `dark-rd1225-390.jpg`, `dark-oras-390.jpg`, `dark-settings-390.jpg`). Слишком ярких/непрозрачных поверхностей нет. Количественный контраст (WCAG) не измерялся.

## 6. Оценка и итоги

### 6.1 Общая оценка
База адаптивности хорошая: 0 горизонтальных переполнений страниц, нет коллизий верхних панелей, нижняя навигация и safe-area-переменные ведут себя корректно, редактор пригоден на телефоне. Основные недоделки — локальные: набор кнопок Мессы, масштаб акклямаций и сетка диоцезий.

### 6.2 Наиболее серьёзные проблемы
1. №1 кнопки наборов Мессы налезают друг на друга (P1).
2. №2 «Гэта слова Божае/Пана» не масштабируется (P1).
3. №3 обрезка заголовка секции при большом шрифте на 320 (P1).
4. №4 диоцезии не 2×2 (P2).
5. №5 тень закрытого drawer на левом краю (P2).

### 6.3 Успешно проверенные компоненты
Главная; список часов (`OrasList`); страницы часов (Заклік, Ютрань, Гадзіна чытанняў, Нешпары, Камплета); верхние панели и sticky-капсула часа; выпадающий список часов; меню-drawer (прокрутка до «Уваход» работает); диалог календаря (укладывается в 320×640); Ordo / «Літургічны дзень» / picker; Малітвы (список, просмотр, навигация по разделам Мессы); тёмная тема; нижняя навигация и safe-area переменные; редактор чтений (включая «Секвенцыя» и альтернативное чтение).

### 6.4 Непроверенные разделы и причины
- **Реальный iOS Safari / WebKit**: в `ms-playwright` нет WebKit; только Chromium. Поведение `100vh/dvh`, плавающей панели Safari, backdrop-filter и шрифтов на iOS не проверено.
- **Реальная экранная клавиатура** и `visualViewport` — только уменьшение viewport.
- **Прямые `env(safe-area-inset-*)`** (BackToTop, NextHourLink, MassSectionNav, compendium) — только статически.
- **Свежие данные продакшна** (ресинк чтений 13.10): использован локальный снапшот; для Пасхальной вігіліі наборов Мессы в данных нет, для 24.12 — два варианта.
- **Не открывались/не просматривались глубоко**: `/admin/day-editor`, PriestAccess, YearOverrides, SongEditor, Bible, Compendium (внутренние страницы), Songs (внутри списка), Пальмовая нядзеля «Муку Пана по ролях» (прокрутка до роли Христа), диалоги избранного/сортировки молитв.
