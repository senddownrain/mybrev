печатные страницы 160–161: 24 декабря использует свой формуляр Ютрані;
на других датах допустима альтернатива, кроме 21/23 декабря. Раздел
24 декабря, с. 208, сохраняет псалмы соответствующего дня IV недели.
Выбор альтернативы на разрешённых датах — редакционная политика MyBrev;
использование датированного антифона в других Ordo само по себе не ошибка.

## Реализация

`assembleDaysResult` использует `lectionaryCyclesFor(date).sunday` из
существующего Ordo (`src/utils/ordo/season.js`). Новый литургический год
начинается с I воскресенья Адвэнта. Цикл нельзя вычислять только по номеру
гражданского года: в декабре 2026 действует литургический 2027, цикл B.
Календарные определения, диоцезии и алгоритм Ordo не изменены.

`resolveAdventDateAgainstPeriod` меняет только `laudesAntBen` IV воскресенья
и собственные поля Ютрані 24 декабря. Псалмы, O-антифоны, I/II Нешпары и
остальные часы сохраняют правила #209.

Точный исходный HTML тройки хранится в
[`advent-benedictus-by.json`](../src/data/liturgical/advent-benedictus-by.json).
Точечный переходный слой использует его **только** вместо известного старого
значения `advent-w4-d1.laudesAntBen`. Будущая редакция поля не перезаписывается.
Если поле уже содержит A/B/C, выбирается вариант из него. Пропущенный,
непроверенный безымянный или неоднозначно размеченный вариант возвращает
пустое значение с `_fieldSources.laudesAntBen.status = 'missing-source-text'`;
дата или другой цикл не маскируют дефицит. Аналогично отсутствующий
обязательный proper 21/23/24 не заменяется воскресным антифоном.

Парсер разделяет варианты по явным меткам `Год А:`, `Год B:`, `Год C:`;
поддерживаются латинские A/B/C и кириллические А/В/С, `<br>` внутри одного
абзаца и отдельные абзацы. Сохраняются общий заголовок и выбранный текст.
Позиция в массиве не определяет цикл. В компонент передаётся ровно один
антифон, одинаковый до и после Песни Захарыі.

Обновлён `CONTENT_REVISION`, чтобы пересобрать сохранённые результаты.
В ограниченную публичную fixture #209 добавлены только поля Ютрані
`advent-24-12`, необходимые для проверки полного формуляра; метаданные
чтения записаны отдельно. Полный Firestore backup в Git не добавлялся.

## Точный контракт для Flutter

1. Вход: реальная дата, день недели, неделя Адвэнта из действующего Ordo,
   `readingCycle.sunday` A/B/C, исходные `advent-w4-d1` и `advent-DD-12`.
   Диоцезия не меняет это правило. Область применения — IV воскресенье.
2. На 21/23 декабря выбрать **только** `advent-DD-12.laudesAntBen`.
3. На 24 декабря выбрать собственные `laudesHymn`, `laudesAnt1/2/3`,
   `laudesR` (включая рэспансорый), `laudesAntBen`, `laudesInter`, `laudesPr`
   из `advent-24-12`. Псалмы — действующий воскресный слот IV недели:
   `advent-w4-d1.laudesPs1/2/3`. Не заменять всю Ютрань обычным воскресеньем.
4. На других датах выбрать **одну** воскресную альтернативу по явной метке
   текущего цикла, не по индексу и не по гражданскому году. Пока база
   содержит подтверждённое старое значение, использовать точный проверенный
   белорусский HTML из приложенного JSON; тот же guard сохраняет будущие
   редакторские изменения. Для воспроизводимости переносится и источник.
5. Сохранять provenance: `{document, field: 'laudesAntBen', cycle}` для
   альтернативы; при переходном HTML также `edition` с путём первоисточника.
   Для proper даты — `{document: 'advent-DD-12', field: 'laudesAntBen'}`.
   Отсутствие нужного текста — явный `missing-source-text`, без подмены
   антифоном даты, другим циклом или непроверенным текстом.
6. Передавать в рендер один и тот же выбранный HTML до/после Benedictus;
   не оставлять A/B/C на произвольном пользовательском выборе по умолчанию.
7. Не менять правила #209 для O-антифона гражданской даты, I/II Нешпараў,
   вечернего псалтыря и остальных часов. III воскресенье 17 декабря
   не подпадает под новое правило IV воскресенья.
8. Инвалидировать кеш собранных дней. Повторить матрицу выше, негативные
   проверки и сравнение всей Ютрані 24 декабря с сохранённым первоисточником.
