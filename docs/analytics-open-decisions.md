## Реальная сеть — отдельный финальный release-проект (не делается сейчас)

Условный этап «P10» (`05_PRODUCTION_RELEASE_AFTER_OWNER_APPROVAL.md`), **только после** подписанных D-01…D-09 и G1…G13:

1. **PR с кодом:** клиентский sender за отдельным build/server flag; kill switch (серверный, работающий без обновления приложений) и клиентский opt-out; consent + опубликованная политика; без user/device/session ID.
2. **Юридический пакет:** заключение, DPA, настройки логов периметра, декларации магазинов.
3. **Security/replay review:** защита от replay/абьюза, авторизованный read, аудит без данных религиозной активности.
4. **Staging acceptance:** закрытый staging на синтетике (R1–R3 плейбука): все POST 503 при выключенном ingress, 4xx на невалид, D1-бюджет при N конкурентных запросах.
5. **Controlled rollout:** отдельное явное разрешение владельца на production и дату; минимальная доля трафика; мониторинг без истории отдельного человека.
6. **Rollback:** выключить ingest (kill switch), клиентский gate, восстановление по утверждённым срокам.

**Ни один из этих шагов не выполнен и не запущен в P09.**
