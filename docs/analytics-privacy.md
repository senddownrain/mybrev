# Аналитика: privacy / legal gates

**Этот документ — не юридическое заключение и не разрешение на сбор.** Он фиксирует найденные факты
с источниками и всё неподтверждённое помечает `НЕ ПОДТВЕРЖДЕНО`. Юридическая оценка не проведена
только потому, что она описана в Markdown. Где нужен внешний специалист или решение владельца —
сказано прямо. Вывод по умолчанию на сегодня:

> **Везде — local-only. Сетевая передача аналитики запрещена до закрытия решений D-01…D-08.**
> Сейчас серверная аналитика не собирается, endpoint не существует, отправителя в коде нет.

Дата проверки внешних источников: 2026-10-14 (WebFetch официальных страниц). Источники могут
измениться — перепроверять перед решением.

## 5. Почему именно local-only / network-off

1. Правовое основание передачи не подтверждено ни для одной ячейки матрицы (F9: текст 99-З не
   получен; нет заключения юриста).
2. Пакет одного устройства с IP транспортного запроса может быть идентифицирующим; «агрегат на
   одно устройство» ≠ анонимность.
3. Данные о том, какие молитвы и когда открывает человек, потенциально относятся к сведениям о
   религиозной практике; для разных юрисдикций категория особая (гипотеза, не подтверждено).
4. Apple 5.1.1(ii) требует согласия независимо от анонимности (F1).
5. Нет внешнего обработчика с подписанными условиями; Cloudflare как обработчик не оформлен.
6. Контракт и валидатор нужны независимо от принятия решений; их готовность не означает
   разрешения.

## 7. Что не делается (подтверждения от запретов задачи)

Нет `user_id`, installation ID, advertising ID, постоянных ID устройства/браузера, session ID для
серверной корреляции, analytics-cookies, fingerprinting, привязки к IP/email/Auth. Не передаются
поисковые запросы, личные молитвы, заметки, пожертвования, закрытые материалы. Ни одной сетевой
отправки в коде не добавлено.
