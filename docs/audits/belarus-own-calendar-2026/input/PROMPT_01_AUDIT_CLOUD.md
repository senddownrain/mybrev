## Нормативная постановка

Предоставленный комиссией `Уласны каляндар дыяцэзій на Беларусі` претендует на полноту всех собственных празднований для диоцезий Беларуси, подтверждённых римскими решениями: `2366/96/L`, `2270/96/L`, `796/03/L`, `417/12/L`, `371/00/L`, `209/23`. Не требуй тексты каждого декрета для того, чтобы использовать PDF как согласованный *рабочий эталон*, но не объявляй самостоятельную проверку декретов проведённой.

ВАЖНО: PDF включает Общий римский календарь/Европу, общее для Беларуси и 4 диоцезальных изменения. Красная `*` означает собственные празднования. На странице 1: «Калі не пазначана літургічная ступень – успамін неабавязковы». Следовательно, строка без ранга = optional memorial, не «отсутствие празднования». Актуальные изменения **Общего римского календаря** после PDF отдельно проверяются по официальному первоисточнику. Примеры из ежегодных Ordo НЕ доказывают наличие обще-диоцезального права. В частности, `04/P/20` по тому Литургии часов утверждает белорусские тексты, не календарь.
