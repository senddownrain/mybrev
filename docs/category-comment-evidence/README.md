# Категории и комментарии в Web

Скриншоты сняты в Chromium на локальных синтетических данных. Сценарий использует реальный Web reader, Settings и Drawer, публичный Hosting JSON и управляемые поколения доступа. Тексты на изображениях служат примерами интерфейса.
