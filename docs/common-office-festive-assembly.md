# Праздничная сборка существующих Common-вариантов WEB

Выбор варианта уже реализован в `assemblyChoices` / `assembledTemplates`:
Proper берётся из `liturgicalProperTexts` (с совместимостью с прежними `days`),
Common — из `liturgicalTemplates`, Feria — из текущего temporal-документа.
`assembleOffice` уже поддерживает приоритет собственных текстов, ссылки
`_fieldRules`, сезонные варианты Common, происхождение полей и диагностику.
Чтение и его респонсорий хранятся вместе в полях `R`, `R1`, `R2`.
Псалмы/песни и антифоны хранятся отдельно: `Ps1…3`, `Ant1…3`.

Изменение ограничено уже доступным выбором Common у воспоминаний:

- Ютрань: Proper, затем Common; псалмы/песнь — из существующего
  `sunday-week-1`, если нет собственных текстов или явного собственного правила.
- Нешпары и Гадзіна чытанняў: Proper, затем выбранный Common.
- Отсутствующий элемент остаётся пустым и попадает в `missing` /
  `_missingFields` и `integrity` / `_integrityErrors`; автоматической
  будничной замены, в том числе первого чтения, нет. Явные структурированные
  правила источника продолжают действовать.
- Собственная молитва и собственное второе чтение сохраняются.
- Te Deum учитывает праздничную сборку выбранного варианта в существующем
  ридере; календарный descriptor и ранг остаются прежними.
- Для расширенного Common-варианта не материализуются первые Нешпары.
  Дневные часы и Комплеторий сохраняют прежнюю сборку.

Вариант «З дня», существующая сборка праздников/торжеств и legacy-документы
не изменены. Новых Common-привязок, переключателей и копий псалмов нет.
Обновлена существующая `CONTENT_REVISION`: сохранённые результаты сборки
должны обновиться при следующей загрузке online; offline-копии сохраняются.

«читай с файрстор» выполнены адресные read-only чтения 19.10.2026:

- `liturgicalProperTexts/19-10-sv-paul-of-cross`;
- `liturgicalTemplates/pastors`, `religious`, `sunday-week-1`;
- `days/ordinary-w29-d2` (ID вычислен существующим resolver);

чтение с респонсорием и молитву, ссылки молитв Ютрані/Нешпараў на неё.

При завершении PR проверено, означает ли отсутствие поля отсутствие текста.

В `assembleOffice` добавляются только временные структурированные правила
`{ source: 'template', template: 'holy-men' }` для этих пустых полей,
которые проходят через существующий resolver. Приоритет — Proper,
собственный текст/явное правило выбранного Common, подтверждённая ссылка.
Сезонный вариант базового Common учитывается тем же механизмом.
Общие кешированные шаблоны не мутируются. Если источник или поле недоступны,
остаётся пустое значение с диагностикой именно `common:holy-men`;
будничная подстановка запрещена.

Область новой ссылки сознательно ограничена `_celebrationId == sv-paul-of-cross`
в праздничном варианте `religious`. Мужской/женский базовый Common для других
святых не угадывается по заголовку и не задаётся всем законникам автоматически.
Их сборка, дневные часы, Комплеторий, первые Нешпары и календарь этим
дополнением не меняются.

## Invitatorium

Существующий `assembleOffice` уже правильно разрешает `invitatoriumAnt`:

| Выбор Павла Креста | Источник антифоны при отсутствии Proper |
| --- | --- |
| «З дня» | `days/ordinary-w29-d2.invitatoriumAnt` |
| «Пра пастыраў» | `liturgicalTemplates/pastors.invitatoriumAnt` |
| «Пра законнікаў» | `liturgicalTemplates/religious.invitatoriumAnt` |

Собственная пригласительная антифона святого всегда выигрывает во всех
трёх вариантах; у Павла Креста отдельной собственной антифоны нет.
`Invit.vue` и `Morning.vue` используют уже собранную антифону и отдельно
накладывают выбранный пригласительный псалом. Адресная read-only проверка
коллекции `invitatoriums` показала четыре документа, содержащих только
`invitatoriumPs1…6`, без `invitatoriumAnt`: антифона не затирается.
Выбор псалма (`getDefaultInvitatoriumId`) и оба экрана оставлены без изменений.

Firestore не изменялся, snapshot не обновлялся, content manifest не
публиковался. Полные live-тексты и приватный backup в patch не включены.
Миграция, новые документы и команды записи/публикации не требуются и
не подготовлены: задача решается только композицией существующих источников.
