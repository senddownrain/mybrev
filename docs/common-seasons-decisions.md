## Решения, блокирующие выпуск

### 1. NR-001. Форма «аллелюя» у К. / Н. в пасхальный период
- **Ситуация.** После 97 строк К./Н. (версикулы и ответы респонсориев) в томе II стоит пометка `(Велікодны перыяд Аллелюя)`. Печатной пасхальной формы такой строки нет ни в одном из трёх томов, поэтому текст не создан: на Пасху показывается базовый текст.
- **Предложение.** Добавлять «…, аллелюя.» (правило `alleluia-v1-versicle`). Для антифон форма «…, / аллелюя.» взята из книги (она сама печатает её в 26 пасхальных антифонах) и уже применена.

## Что остаётся сделать после решений

1. Применить решения (см. выше), перегенерировать данные, прогнать тесты.
2. Бэкап и `npm run ordo:import-feasts -- --apply --only templates` (14 из 16 шаблонов, +570 КБ). Делать после сброса квоты Firestore (около 10:00 по Минску 14 октября).
3. `npm run content:version:bump` и деплой сайта. Порядок важен: сначала импорт, потом версия, иначе кеш закрепит тексты без вариантов.
4. `npm run content:manifest` (сухой прогон), `-- --apply` только при вердикте SAFE CONTENT PATCH.
5. Flutter отдельным заданием: `docs/common-seasons-flutter-handoff.md` и файл сверки `reports/liturgy/common-seasons-flutter-fixture.json` (3984 случая). Пока приложение не обновлено, оно в Пост, Пасху, Адвент и Рождество показывает текст обычного времени.
