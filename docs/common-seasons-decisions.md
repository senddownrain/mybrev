# Сезонные «Агульныя тэксты»: решения редактора и владельца

Состояние на 2026-10-16, ветка `feature/common-seasons-finish` (PR #132). **D-1…D-7 решены владельцем и выполнены в коде и данных репозитория; ничего не опубликовано** (ни Firestore, ни manifest/версия, ни Hosting, ни Flutter). Подробности: `reports/liturgy/common-seasons-audit.{md,json}` (матрица, тома, строки), `reports/liturgy/common-seasons-base-corrections.md` (исправления базы), приёмка и вердикты — `reports/liturgy/common-seasons-acceptance.md`.

## Принятые решения редактора и как они выполнены

| № | Решение | Результат |
|---|---|---|
| NR-001 | «аллелюя» к К./Н. пасхальных респонсориев — принять | `, аллелюя.` у 100 строк тома II (только к тем, после которых стоит `(Велікодны перыяд Аллелюя)`); краткие «ответы» не меняются; дублей нет (проверено по каждому полю) |
| NR-002 | `church-dedication.officeOfReadingsAnt2`: не добавлять † | Пасха: «2 ант. Якія мілыя Твае шатры, * Пане Магуццяў! / аллелюя.» без †. † напечатан и в томе III (после антифоны), и в томе II (после пометки) и начинает вторую строку псалма 84 (83); база обычного периода не менялась |
| NR-003 | `apostles.officeOfReadingsPs2`: полная повторная сверка | Псалом 64 (63) сверен по словам с томом II: расхождений в тексте псалма нет (0 из 139 слов). Расходились только антифоны: том III печатает «абвяшалі справу» (2 ант., стр. 1703) и «абвяшалі справы» (повтор, стр. 1733) при стихе «абвесцяць справу Бога» того же тома; во всех томах глагол — «абвяшчаць»; тома I и II — «абвяшчалі справу». База исправлена отдельным коммитом, Пасха = база + аллелюя |
| NR-004–006 | `religious` / `works-of-mercy`, `officeOfReadingsR1` | Методика исправлена (сравнение раздела с разделом): целое чтение с заголовком, ссылкой, текстом, респонсорием (в т. ч. «Пра законнiцу: Лк 10, 42. 39»). `religious`: Эф 4, 1–24 вместо Флп 3–4; `works-of-mercy`: 1 Ян 4, 7–21 вместо 1 Кар 12–13. Пост — без аллелюя, Пасха — с аллелюя в трёх размеченных строках; Адвент/Рождество — то же чтение по тому I |
| NR-007–009 | К./Н. переставлены в базе | `apostles`, `virgins`, `holy-women`: отдельный коммит, К. первым. Замечание: для `holy-women` том II повторяет ошибку тома III — верен только том I (основание: Пс 19 (18), 15 и порядок во всех остальных Common) |
| NR-010 | «аллеюя» → «аллелюя» | 3 строки тома II (118, 527, 1167; 4 слова) |
| NR-011 | Страстная неделя | `holyweek/palm-sunday` и `holy-week` → Пост; `triduum` и неизвестная фаза → база. Фазу даёт Ordo по ДАТЕ (чётверг целиком — `triduum`), поэтому утро Великого четверга читает базу; ни одно Common-Office не выпадает на эти дни (2026–2060, 4 епархии, тест) |
| NR-012 | Молитвы Найсв. Панны Марыі | Адвент и Рождество: одна сезонная молитва тома I, без шести необязательных и без второй сезонной рубрики; обычное время сохраняет список; собственная молитва празднования приоритетнее. Субботний успамин (в томе III он — только для суббот Звычайнага перыяду) см. вопрос D-2 |
