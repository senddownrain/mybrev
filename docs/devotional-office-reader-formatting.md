# Оформление ридера пяти набажэнстваў

В Гадзінках вложенный `### Гімн` теперь использует общий `h2.ora-title`.
В Ютрані и Нешпарах название короткого чтения и респонсория используют тот
же заголовок раздела, а ссылка чтения выводится отдельно. Текст чтения
сохраняет обычный размер ридера; повторный импортированный заголовок скрыт.

Респонсорий выводится одним компактным блоком с переносом перед каждой
репликой `К.` / `Н.`. Поддерживаются метки без пробела, с двоеточием,
обычные и выделенные Markdown, реплики в одном абзаце и разных абзацах.
Метки используют существующий `--rubric-color`. Такое разбиение действует
только внутри респонсория этого ридера.

Евангельская песня сохраняет общий заголовок и получает семантический
подзаголовок `h3` с собственным названием и ссылкой. Её текст продолжает
проходить через общие `formatPsalmHtml` и `PsalmText`: строфы, чередование
отступов, переносы после `*` / `†` и режим приглушения сторон. Регрессии
охватывают песни Марыі, Захарыі и Сімеона. Антифоны остаются отдельными
блоками и не входят в чередование строф.

Парсер исходных блоков, литургические тексты и варианты в базе не переписываются.
Профили по пяти ID и проверка структуры остаются ограничением входа в ридер.
Обычный ридер остальных молитв не изменён. Firestore, manifest приложения,
production и merge не выполнялись.

## Проверка

- `npm run lint`
- `npm test`
- `npm run build`
- `npm run smoke:devotional-office` при локальном Vite на `127.0.0.1:4174`.

Браузерный smoke-тест монтирует настоящий компонент с Pinia, маршрутизатором,
темой проекта и общими стилями. Все внешние запросы блокируются: Firestore
не читается и не изменяется. Тёмная тема проверена на 390 и 320 px,
также 320 px при увеличении текста до 200%. Проверяются отсутствие
горизонтального скролла и ошибок JavaScript, единичные заголовки,
отдельная ссылка, обычный размер чтения, акцент меток и отсутствие
пустых строк между репликами, оба режима отступов и переносов,
чередование строф и неизменность текста песен.

Тестовые тексты синтетические и воспроизводят описанные формы данных.
Полные исходники из частного локального аудита и пять приложенных
пользователем скриншотов недоступны в этой среде. Проверка авторизованного
admin preview и опубликованных документов не проводилась.
Внешние шрифты не загружаются; скриншоты используют предусмотренные CSS
резервные шрифты. Два существующих unit-теста с частными полными
источниками пропускаются без соответствующих локальных файлов.

Результат полного прогона: 1011 тестов, 1000 прошли, 10 пропущены,
один упал — `Marian feast references are structured rules resolved from the Common`
в `tests/marian-feast-references.test.mjs:55`, поле `vesper1Ps1`.
То же падение воспроизведено отдельным запуском этого файла в чистом
checkout исходного коммита `247251f`; к изменениям ридера оно не относится.
Точечный прогон ридера: 17 прошли, два существующих теста с частными
источниками пропущены. Lint, финальный build и браузерный smoke прошли.
Build сообщает о чанках больше 650 kB.
