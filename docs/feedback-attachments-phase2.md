# Вложения (скриншоты) к обращениям — фаза 2

**Статус:** не реализовано, не блокирует релиз. Форма сегодня не принимает файлы; политика конфиденциальности прямо об этом говорит. Фаза 2 стартует отдельным PR после решения владельца по пунктам ниже.

## Принципы
* Опционально, до 3 файлов, PNG/JPEG/WebP, до 2 МБ каждый; проверка по сигнатуре (magic bytes), не по расширению. Никаких SVG/PDF/HTML.
* Клиент перекодирует изображение (canvas / Flutter `image`) в WebP без EXIF и геотегов; пользователю показывается превью и кнопка «Закрасить область» (скрыть личное) до отправки.
* Файл никогда не публичен. Хранение — Cloudflare R2, приватный bucket без публичного домена; в D1 только `feedback_attachments(id, feedback_id, object_key, size, mime, sha256, created_at)`.
* Доступ — только через Worker: тот же Firebase ID-token и та же ролевая проверка, короткоживущая подписанная ссылка (≤ 5 мин) или потоковая выдача `GET /api/admin/feedback/:id/attachments/:aid`, `content-disposition: attachment`, `x-content-type-options: nosniff`, `content-security-policy: sandbox`.
* ACL: админ видит вложения только в обращениях `text_error`/`content_suggestion`; суперадмин — во всех. Вложения не попадают в экспорт для AI-анализа.
* Загрузка: сначала `POST /api/feedback` создаёт обращение, затем `PUT /api/feedback/:id/attachments` с одноразовым upload-токеном (HMAC от id + срок), чтобы анонимный клиент не мог писать в чужие обращения. Лимиты: 3 файла/обращение, общий дневной бюджет байтов, rate-limit как у текста.
* Хранение и удаление: срок как у обращения (180 дней после закрытия), каскадное удаление объектов R2 в ежедневном cron; удаление по просьбе пользователя — вместе с обращением.
* Приватность: обновить политику (файлы, R2, срок), добавить предупреждение «на скриншоте не должно быть личных данных».

## Проверки перед релизом фазы 2
* Тесты Worker: неверный MIME/сигнатура, размер, количество, чужой upload-токен, role scope, подпись ссылки, отсутствие объекта после purge.
* Ручной QA: Web + Android + iOS, 320/390 dp, отказ в разрешении на фото, большой файл, обрыв сети посреди загрузки (повтор не создаёт дубль).
* Решения владельца: включать ли R2 (платный сверх бесплатного лимита), кто имеет право открывать вложения, нужен ли редактор закрашивания в первой версии.
