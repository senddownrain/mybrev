# Святая Імша: моўныя варыянты

Святая Імша — адзін рытуал `order-of-mass` з некалькімі моўнымі варыянтамі.
Метаданыя рытуалу ляжаць у `src/data/mass/order-of-mass.ritual.json` (`schemaVersion: 2`;
тая ж копія выкарыстоўваецца ў ibreviarybyapp у `assets/mass/`).

| Мова | Крыніца | ID малітвы |
|---|---|---|
| `be` (па змаўчанні) | існуючая малітва «Парадак святой Імшы» (Firestore) | `eMmCtxwyJ75ogmL5rwye` |
| `la` | існуючая малітва «Ordo Missae» (Firestore, тэкст не дубліруецца) | `zdro66KYVuQ9p2KbqizD` |
| `en` | `MCFL.pdf` (The Order of Mass, ICEL 2010 / CBCEW 2011) | `order-of-mass-en` |

Англійскі тэкст захоўваецца ў `src/data/mass/order-of-mass-en.md` і перанесены з PDF
без дапаўненняў. Пакуль дакумент `prayers/order-of-mass-en` не апублікаваны, чытач бярэ
ўбудаваны тэкст. Апублікаваць: `npm run db:import-mass-english` (dry run) і потым
`-- --apply` (толькі стварае дакумент, не перазапісвае).

## Два слаі

1. **Змест** застаецца ў Firestore / `.md` без змен. Структурная нармалізацыя робіцца
   дэтэрмінаваным адаптарам `src/utils/massContent.js` (`buildMassDocument`), які
   толькі перагрупоўвае існуючы тэкст у семантычныя блокі. Словы, пунктуацыя і
   рубрыкі не мяняюцца (гл. тэст «wording preserved»).
2. **Чытач** (`renderMassBlocks`, `PrayerView.vue`, `prayer-reading.css`) малюе блокі
   аднолькава для ўсіх моў.

## Раздзелы

Роўна пяць галоўных раздзелаў (заўсёды па-беларуску, незалежна ад мовы тэксту):

| id | Назва |
|---|---|
| `introductory-rites` | Уступныя абрады |
| `liturgy-of-the-word` | Літургія слова |
| `eucharistic-liturgy` | Эўхарыстычная літургія |
| `communion-rite` | Абрад Камуніі |
| `concluding-rites` | Заключныя абрады |

Ранейшы id `liturgy-of-the-eucharist` застаўся ў `aliases`. Падраздзелы (Gloria, Credo,
Ойча наш…) — дзеці гэтых пяці і ў ніжнюю навігацыю не трапляюць.

У кожным варыянце:

- `markers[sectionId]` — блок, які становіцца бачным загалоўкам раздзела;
- `anchors[sectionId]` — блок, які захоўвае свой тып і толькі нясе якар раздзела
  (для выраўноўвання пры змене мовы, калі ў крыніцы няма загалоўка).

Маркер супадае з нармалізаваным тэкстам блока цалкам; маркер, які заканчваецца на `…`,
супадае як прэфікс. Раздзелы шукаюцца ў парадку рытуалу, кожны пасля папярэдняга.

Пры змене мовы: той жа раздзел → бліжэйшы папярэдні суседні падраздзел → бацькоўскі →
бліжэйшы папярэдні → наступны. Спасылка `#mass-<id>` адкрывае чытач на раздзеле.

## Тыпы блокаў і ролі

`majorSection`, `subsection`, `heading`, `rubric`, `comment`, `posture`, `alternative`,
`spoken`, `response`, `separator`. Правілы адаптара па парадку:

1. Markdown-блокі: загаловак → `heading`, `:::rubric` → `rubric`, `---` → `separator`,
   абзац → `spoken`.
2. Абзац дзеліцца: `strongMarksResponses` (en) — радкі цалкам тлустым шрыфтам →
   `response` (роля `people`); інакш па прэфіксах `speakerLabels` (`С.:`, `Н.:`,
   `Цэлебрант:`, `Усе:`, `V.`, `R.`) — прэфікс становіцца роляй і не паказваецца.
3. `classify` (heading/rubric/comment/posture/alternative) па тым жа правіле маркераў.
4. Прэфікс без тэксту (`V.`) аддае ролю наступнаму радку.
5. Рубрыка без канчатковага знака + кароткі (≤4 словы) аднарадковы тэкст + рубрыка з
   малой літары ці знака прыпынку → адна рубрыка з цытатай (`Потым спяваецца
   «Аллелюя» альбо…`).
6. `roleCues` (be): апошняя фраза ў рубрыцы («народ адказвае», «усе разам»…) дае ролю
   наступным радкам да наступнага не-`spoken` блока.
7. Ролі з `rolePolicy.responseRoles` (`people`, `all`) → `response` (тлусты шрыфт).
8. Знойдзеныя `markers` → `majorSection`/`subsection`, `anchors` → толькі якар.

Палітыка роляў: `rolePolicy.showSpeakerLabels = false` — ні ў адной мове скарачэнні
не паказваюцца, роля захоўваецца ў `data-role`, частка народа/усіх — тлустым.

## Навігацыя і стан

- `/prayer/eMmCtxwyJ75ogmL5rwye?lang=la|en|be`; старыя спасылкі на ID лацінскай ці
  англійскай малітвы перанакіроўваюцца туды з адпаведнай мовай.
- Апошняя выбраная мова захоўваецца ў `localStorage` (`massRitualLanguage`).
- Шапка: толькі кнопка меню (без «Назад» / «Усе малітвы»), без «Падзяліцца»;
  кампактнае меню мовы BE/LA/EN.
- Унізе — пяць раздзелаў роўнай шырыні, назвы ў два радкі па цэнтры; калі найдаўжэйшае
  слова («Эўхарыстычная») не змяшчаецца, толькі гэтая ячэйка шырэйшая.
