# Ordo: епархиальные различия

> Генерируется `npm run ordo:docs` из `src/data/ordo/diocesan-differences.json` и `notes.json`.
> Выравнивание — по идентичности празднования (fixed `MM-DD` / movable code), не по гражданской дате:
> Мінск и Віцебск 2025–26, Пінск 2026, Гродна 2027. `*` — альтернатива («Або:/Дазволена:»),
> «імпед.» — в этом году день занят более высоким рангом, «н/п» — дата вне покрытия.

## Только различия конкретного года (YEAR_SPECIFIC)

84 празднований различаются только из-за календаря года (нядзеля, Пост, актава, перанос). Пример: `annunciation-lord`, `beheading-john-baptist`, `chair-of-saint-peter`, `conversion-saint-paul`, `dedication-st-mary-major`, `fixed-0103-2`, `heartofmary`, `holy-innocents`, `nativity-blessed-virgin-mary`, `our-lady-mount-carmel`, `our-lady-queen`, `presentation-blessed-virgin-mary`.
