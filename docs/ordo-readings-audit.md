# Чытанні: аўдыт спасылак і зместу

Згенеравана `npm run ordo:audit-readings` (крыніца: public read-only cache 20260930114742892). Не рэдагаваць уручную.

Правяраецца кожнае празднаванне, якое engine выдае як primary або alternative ў гадах
чатырох календароў: чаканыя чытанні Ordo ↔ `readingsRef` ↔ знойдзены дакумент
`readings` ↔ цытаты ў дакуменце.

| Статус | Колькасць | Значэнне |
|---|---|---|
| MATCH | 110 | дакумент з тэкстам; Евангелле супадае з календарамі (або каляндар цытату не друкуе) |
| WEEKDAY_DEFAULT | 127 | успамін без уласных чытанняў: бяруцца чытанні будня — гэта норма |
| REFERENCE_ONLY | 6 | тэксту няма, але цытата вядомая з календароў |
| MISSING_CONTENT | 2 | урачыстасць / свята без дакумента і без цытаты |
| WRONG_LINK | 0 | дакумент звязаны (`_dayId`) з іншым празднаваннем |
| WRONG_CITATION | 6 | Евангелле ў дакуменце адрозніваецца ад усіх календароў |
| AMBIGUOUS | 2 | на запыт адказвае некалькі розных дакументаў |
