## Мінск (DOCX) — адаптер по стилям абзацев

Структура: заголовки периода (`Zagol-12-caps-bold`: «ПЕРЫЯД АДВЭНТУ», «ВЯЛІКІ ПОСТ»…),
правила периода (`Osn-10`: «Каляндар.», «Імша.», «Літургія гадзінаў.»), «Псалтыр N тыдня»
(`Zag11maly`), «Аб’явы:» (`ABJAVYBOLD`/`Abjavy`), дни:

```text
Dzien      + 7. – ІІ НЯДЗЕЛЯ АДВЭНТУ            ("+" = нядзеля/урачыстасць)
Koler      Ф<TAB>Імша ўласная, Веру, І прэфацыя…  (буква = колер)
Czytanni   1 чыт.: Іс 11, 1-10; Пс 72 …
Uspamin    Або: Успамін св. Яна Дамаскіна         (неабавязковы ўспамін + свой Koler/Czytanni)
Liturgia-10-bold / swiatar / None
           Літургія гадзінаў з будня або з успаміну, 1-я Нешпары з …; заметки; клир
```

Стратегия: стиль — подсказка, содержание решает (многие абзацы без стиля или с «чужим»
стилем: дни `+ 2. – …` без `Dzien`, «Альбо:» отдельным абзацем, продолжения Koler-строк).
Месяц/год — из заголовков месяцев, fallback — «переполнение» номера дня + проверка
аббревиатуры дня недели. Клир (імяніны, дні нараджэння, гадавіны пасвячэння/смерці) — в
`swiatar` и без стиля; исключается абзацем целиком (+ продолжения списков имён).

## Віцебск (DOCX) — state machine

Почти нет стилей; структура кодируется жирным и цветом:

- `FRONT`: цветные (4472C4) заголовки → разделы правил: таблица первенства, агульныя
  нормы, Эўхарыстыя (+ таблицы Імшаў), парадак ЛГ (нядзеля, трыдуум, урачыстасці, **святы
  без І Нешпараў**, ўспаміны в звычайныя/асаблівыя дні), дні пакаяння, рухомыя святы,
  **уласны каляндар Віцебскай дыяцэзіі** (→ `DIOCESAN_PROPER`).
- `CALENDAR`: `D <месяц> – ДЗЕНЬ – назва – ГОД А`; `<колер>\t<чытанні>`; `✠\t<Імша, Афіцый>`
  (✠ = pro populo); `<колер>\tальбо: успамін …` (+ своя Імша); синий текст (4472C4/0070C0) —
  навэнны/набажэнствы; «Прапускаецца …» — подавления; «+ кс. …» — некролог.
  Цветные/капс-заголовки внутри календаря = разделы «ПРАДПІСАННІ НА …», привязываются к
  следующему дню (`anchorDate`).
- `PREVIEW`: «ЛІТУРГІЧНЫ ГОД 2026 – 2027» — список титулов на Адвэнт 2026 (`preview: true`;
  опечатка «СНЕЖАНЬ 2027» зафиксирована в `unresolved`).
- `COLLECTIONS` («МЭТЫ ЗБОРУ АХВЯРАВАННЯЎ»), `NECROLOGY` («Памерлыя святары…») — исключаются
  целиком; `BLESSINGS` — только заголовки обрадов (повод = селектор).

## Пінск (PDF) — полосы дней и колонки

A5, 4 дня на страницу. Номер дня — MinionPro 20pt (на некоторых страницах не Bold).
Каждый день — горизонтальная полоса от своего номера до следующего; колонки по x≈140:

```text
левая:   ДЗЕНЬ ТЫДНЯ / назва (bold) / (колер) / чытанні
правая:  Імша: … | ЛГ: … | Або:/Дазволена: усп. … Імша: … | Наб. … | І Нешпары … |
         Урач. тытула касцёла: … | † Кс. … (некролог) | Імяніны: …
```

Правая колонка группируется в абзацы по маркерам, интервалу, смене кегля, концу фразы
(с защитой сокращений «Найсв.», «св.», «Бп»). Мягкие переносы (`U+00AD`) склеиваются.
Строки, идущие через обе колонки (рубрики Вялікага тыдня), распознаются как full-width
блоки. «Аб’явы.» — полноширинный блок в конце субботы (или вверху страницы); якорь —
следующая нядзеля / «Сёння, D месяца»; пункты «– у сераду, 31 снежня, — …» получают
`targetDate`. Страницы без дней — «ЛІТУРГІЧНЫЯ ЎКАЗАННІ» периодов (пункты «•»), front
matter (таблица першынства, «Зацверджаныя літургічныя звычаі» — первые чацвер/пятніца/субота),
«Зборы ахвяраванняў» и «Кантакты святароў» — исключаются.

Известное ограничение: страницы 60–72 (Трыдуум) перемешивают текст указаний и полосы
дней; часть этих абзацев склеена неидеально (сохранены как заметки дня с провенансом).

## Гродна (PDF) — блоки дней, табличные зоны, объявления

Части: I (с. 3–36) уводзіны/табліцы; II (37–143) каляндар; III (144–169) уласныя чытанні
дыяцэзіяльных урачыстасцей (берём только заголовки «Св. Казіміра 4 сакавіка» →
`diocesan-lectionary`); IV (170–186) благаслаўленні (заголовки с поводом/датой); V — малітвы
(пропуск).

Блок дня: номер Times 18pt (x≈62); слева день недели, назва, слово ранга («свята»,
«урачыстасць», «успамін абавязковы»), «колер …», чытанні, некролог «1969 + Кс. …» (7.2pt);
справа (x≥110) «Аф. …, Імша …», «І Нешп. … i І Кампл. нядз.», «Псалтыр N тыдз.», «Або: успамін
…», заметки, «Заўтра: <парафіі> – урач. …, тыт. касц.» (локальные тытулы **следующего** дня).
«Заўтра аб’явіць:» — полноширинный блок с маркерами Wingdings `h`, каждый пункт
«DD.MM -Дз- …» → `targetDate`. Опечатка источника: 3–6.02.2027 напечатаны как 4–7
(исправлено по дню недели, записано в `unresolved`).

## Общие правила извлечения

- Каждый элемент: `SourceEvidence { file, page|paragraph, bbox (PDF), rawText }`.
- Исключения (`EXCLUSION_RULES` в Python и `scripts/ordo/lib/exclusions.mjs`): зборы
  ахвяраванняў, дні нараджэння/імяніны/гадавіны пасвячэння (у т.л. біскупскія, прызначэння,
  інгрэс)/смерці духавенства, некролог, кантакты. Сохраняется только местоположение
  (`excluded[]` без текста). Финальный проход `_sanitize` чистит и `rawText`.
- Категории строк — `categorize()`; «дескрипторы» Імшы/Афіцыя (`Імша: …`, `ЛГ: …`, `Аф. …`)
  идут в `day.mass` / `day.office` как оракул, а их хвостовые фразы-заметки («Першы чацвер
  месяца.») выделяются в отдельные notes.
- Всё литургическое толкование (выравнивание, идентичности, селекторы, классификация) —
  в Node (`scripts/ordo/build.mjs` + `lib/`), на коде самого MyBrev.
