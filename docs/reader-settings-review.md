# Настройки чтения и псалмодии

Ветка: `feat/reader-settings-alignment`, основана на `origin/main` (`a8ca4b4`).

## Изменения

- Существующая секция «Тэкст» сворачивается одним нажатием. Подзаголовок: «Шрыфт, памер і выраўноўванне». Состояние сохраняется локально в том же Pinia-хранилище; начальное состояние — свёрнутое. Используется `v-expand-transition`, учитывается reduced motion.
- Пять прежних значений шрифта и диапазон размера 70–180% сохранены. Прежний пример использует общие CSS-переменные шрифта и масштаба.
- Добавлены две кнопки с иконками Phosphor, доступными названиями и управлением стрелками/Home/End. Тот же компонент `TextAlignmentSettings` включён в существующую панель `TextSettingsSheet`.
- Выравнивание применяется к явно отмеченным абзацам Библии, Чтений, молитв, ответов Катехизиса и обычного текста Імшы через общий читатель молитв. В собственном календаре отмечен только вводный прозаический абзац.
- `vReaderProse` используется только в подходящих читательских компонентах. Он исключает заголовки, метаданные, рубрики, реплики с обозначением говорящего, ссылки, списки, таблицы, стихи с намеренными переносами, псалмы, секвенции и аккламации. Сохранённые тексты не переписываются.
- Компоненты Литургии часов и `DevotionalOfficeReader` не подключают выравнивание. Браузерные проверки сравнивают текст, HTML и вычисленное выравнивание всех абзацев реальной Утрени до/после изменения предпочтения.
- В «Псальмодыя» сохранены три режима и существующие SVG-пиктограммы. На десктопе компактный переключатель справа, на мобильном — три равных сегмента на всю ширину. Зоны нажатия не меньше 44 px.

## Повторное использование

Использованы `useSettingsStore` (Pinia + localStorage), `READER_FONT_OPTIONS`, существующие CSS-переменные тем, компоненты и иконки Vue/Vuetify/Phosphor, `PsalmText`, `formatPsalmHtml` и `decoratePsalmody`. Для примера добавлен необязательный режим `interactive=false`: форматирование общее, действия затемнения и кнопочная семантика в примере выключены. Поведение настоящих псалмов по умолчанию сохранено.

## Источник псалма и контракт Flutter

Пример: **Псальм 63 (62), 2–3**, первые три последовательные строфы основного текста из `patchs/json/ordinary-w5-d1-fixed-day.json`, поле `laudesPs1`. Заголовок и эпиграф исключены. Точное HTML-содержимое и положение фрагмента зафиксированы в `src/constants/psalmodyPreview.js`. Автотест проверяет побайтовое совпадение с источником. Flutter может использовать тот же фрагмент, сохраняя границы трёх строф и маркеры `*`.

| Настройка | Сохранённое значение | Значение для интерфейса / Flutter |
| --- | --- | --- |
| Выравнивание | `start` (по умолчанию) | Па левым краі / `TextAlign.start` |
| Выравнивание | `justify` | Па шырыні / `TextAlign.justify` |
| Псалмодия | `left-break` | Злева з пераносамі |
| Псалмодия | `left-break-indent` | Злева з пераносамі і водступамі |
| Псалмодия | `alternating-stanzas` | Чаргаванне строфаў |
| Семейства | прежние полные значения из `READER_FONT_OPTIONS` | Literata; Source Serif 4; Old Standard TT; Kurale; Сістэмны |
| Размер | прежний `fontSizeMultiplier` | 0.7–1.8 с шагом 0.1 |
| Состояние группы | `textSettingsExpanded`: `true` / `false` | локальное UI-предпочтение |

Новые предпочтения не меняют ранее сохранённые шрифт, масштаб, режим псалмодии или избранное. Установки без нового ключа получают `start`; неизвестное значение безопасно нормализуется. Между устройствами настройки не синхронизируются. `lang="be"` уже установлен на документе, для Библии язык уточняется по переводу. Проза использует `text-align-last: start`, `hyphens: auto`, `overflow-wrap: anywhere`, `word-break: normal`.

## Ограничения

- Внешняя загрузка Google Fonts в тестовой среде заблокирована. Проверены выбор всех пяти семейств, CSS-масштаб и отображение белорусского текста доступными резервными шрифтами; фактические глифы четырёх загружаемых гарнитур требуют отдельной проверки при доступной сети. Существующий механизм загрузки шрифтов не изменялся.
- Автоматические белорусские переносы зависят от словарей браузера. Если словаря нет, длинное слово безопасно переносится только при нехватке места.
- У старых текстов без смысловой разметки применяется консервативная классификация: абзацы с жёсткими переносами, отдельные выделенные подписи и реплики с метками остаются в исходном выравнивании. Они не переинтерпретируются как проза.
- `smoke:responsive` требует Firebase CLI, Firestore emulator и приватных локальных snapshot-каталогов; они отсутствуют. Новая проверка адаптивности выполнена без них. Эмуляторные тесты в `npm test` отмечают собственные пропуски.
- Flutter-код в рамках этой Web-задачи не изменён; терминология, значения и источник примера документированы выше.
