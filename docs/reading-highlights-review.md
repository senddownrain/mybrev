# Цветное выделение предложений в дневных чтениях

Проверено 9 ноября 2026 года на базе `c6a480d` актуального `main`.

## Поведение

- Переключатель «Каляровае вылучэнне ў чытаннях» по умолчанию выключен;
  выбор хранится в settings store и `localStorage.readingHighlightsEnabled`.
- При включении нажатие выбирает/отменяет выбор предложения. Можно выбрать
  несколько предложений, назначить один из четырёх цветов Библии, стереть цвет
  или отменить выбор. Enter/Space поддерживаются с сохранением фокуса.
- Цвета хранятся в `readingSentenceHighlightsV1`, отдельно по ID документа,
  набору Имшы и циклу. Выключение скрывает цвета и очищает только текущий выбор.
- Директива оборачивает фрагменты текстовых узлов, сохраняя вложенную разметку.
  Перед обновлением Vue возвращает исходные Text-объекты; при OFF удаляет свои
  обработчики и обёртки. Источники чтений не переписываются. Переносы строк,
  курсив, альтернативы, псалмы, Евангелие и роли Страстей сохраняются.
- Панель наследует тему приложения, имеет кнопки не менее 44×44 px;
  при включённой функции добавляется место для прокрутки последнего текста
  выше панели.
- `Bible.vue` и хранилище выделений Библии не менялись.
- Инициализация `keepScreenOn` оставлена прежней: отсутствие значения → `true`,
  явно сохранённое `'false'` → `false`. Проверено через интерфейс с перезагрузкой.

Браузерный сценарий использует настоящее приложение с локальными fixtures в
IndexedDB, блокирует все внешние запросы и service worker. Чтения из Firestore
не запрашиваются и данные не записываются. Запуск:

```sh
npm run dev -- --host 0.0.0.0 --port 4174
# В другом терминале:
npm run smoke:reading-highlights
```

В каждой ширине проверяются:

- нативный свайп через CDP touch events при OFF и ON: страница прокручивается,
  выбор от свайпа не появляется;
- четыре цвета во всех трёх темах, непрозрачный фон панели, отсутствие
  горизонтального переполнения;
- точное совпадение текста при ON и исходного HTML после выключения,
  включая переключение без перезагрузки;
- выделение предложения через вложенный `em`, альтернативное чтение,
  псалом и Евангелие, сохранение ролей Страстей;
- выбор клавиатурой, снятие выбора, стирание цвета, перезагрузка,
  OFF → ON без удаления сохранённых цветов;
- смена документа в том же экземпляре карточки, наборов и циклов с одинаковым
  текстом: цвета изолированы и восстанавливаются при возврате;
- значение переключателя после перезагрузки, начальное `keepScreenOn=true`,
  сохранённое пользователем `false`, сохранность выделений Библии.

Скриншоты и машинный отчёт сценарий сохраняет в `work/reading-highlights/`.
Мобильная проверка выполнена в Chromium с эмуляцией touch/viewport;
физические устройства и Safari в этот прогон не входили. Развёртывание сайта
и публикация данных не выполнялись.
