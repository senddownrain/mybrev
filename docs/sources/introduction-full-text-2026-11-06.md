## Проверенная особенность нумерации

В lh.catholic.by после 176 дважды напечатан номер 178. Текст первого из них
начинается «Гімны, уведзеныя нанова…» и соответствует пункту **177**.
Это сверено с [полным GILH литургического отдела епископской конференции
Англии и Уэльса](https://www.liturgyoffice.org.uk/Resources/Rites/GILH.pdf), §177–178.
В MyBrev для первого восстановлен номер 177; слова обоих пунктов не менялись.
На странице есть сноска к номеру и отдельная редакционная заметка с источником.
В сыром снимке остаются оба 178; JSON хранит `number: 177, sourceNumber: 178`.
Таким образом навигация использует последовательные уникальные ID `point-1`…`point-284`,
а происхождение исправления не скрыто.

Номер 140 в источнике стоит отдельной строкой. Он не потерян: следующий абзац
и его продолжение включены в пункт 140, а номер отображается на первой строке.

## Оформление

Одна книжная статья: оглавление пяти глав и двух заключительных разделов,
раскрываемый список всех подразделов внутри каждой главы, устойчивые якоря
пунктов и заголовков. Семантическая иерархия h1–h4, списки с исходными буквами,
читаемая колонка и красные рубричные номера. Проза выровнена по ширине с
`text-align-last: left`, `hyphens: auto`, `lang="be"`. Заголовки, оглавления,
номера и выходная строка © не выравниваются по ширине.
Поддержаны light/dark/marian из main. Многочисленных карточек нет.
