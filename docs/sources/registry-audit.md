## Документально подтверждено

- [Официальная страница Нового Завета](https://catholic.by/3/lib/bible)
  подтверждает первое полное католическое издание, Минск, 2017, и коллектив
  переводчиков; `scripts/bible/parse-bel-nt.py` документирует импорт EPUB.
- [Страница декретов](https://lh.catholic.by/dekrety.php) содержит декреты ККББ:
  I том — № 32/P/12 от 29.06.2012; II — № 70/P/13 от 15.08.2013;
  III — № 62/P/15 от 06.08.2015. Они предписывают использование соответствующего
  студийного белорусского текста при богослужении во всех диоцезиях Беларуси.
  Номера решений об одобрении, приведённые внутри декретов, не подменяют номера
  самих декретов. Римские декреты № 1000/71 и № 1814/84 на той же странице
  **не являются четвёртым декретом ККББ**.
- [Цифровая редакция Чарняўскага](https://bible.by/bvc-2017/) прямо обозначена
  как редакция к изданию 2017; именно этот URL использует
  `scripts/bible/convert-bel-charniauski.py`. [Издательская страница на Bible.com](https://www.bible.com/versions/3637)
  подтверждает название, перевод/редакцию и связь с Библейским обществом.
  Это не доказательство правообладания или разрешения для MyBrev.
- `scripts/bible/upload-bible-bel-firestore.mjs` и существующие `tests/bible.test.mjs`
  подтверждают смешанный корпус Web: Чарняўскі OT + ККББ NT; сборка корпуса
  и библейские тексты не изменялись.
- В `scripts/compendium-source/3963-kampendyj-katekhizisa-katalitskaga-kastsjola.html:359`
  сохранены оба знака ©: LEV 2005 и ККББ 2010.
- Локальные импортные модули документируют цифровые источники Чтений и часов.
  Это свидетельство происхождения импорта, а не доказательство прав сайта на текст.

## Что остаётся проверить

1. Четвёртый декрет ККББ, его номер, дата и содержание: на указанной странице
   только три декрета ККББ. Дополнительный поиск по Catholic.by не установил
   первичный документ. В реестре есть отдельная запись для IV тома со статусом
   `requires_verification`, номером, датой, ссылкой и содержанием `null`.
2. Правообладатель всех томов Литургии часов и точные знаки © по выходным страницам.
   Декрет об использовании не устанавливает передачу цифровых прав.
3. Правообладатель перевода/редакции Чарняўскага 2017; место, издатель и полные
   выходные данные именно этой редакции. Не переносить автоматически сведения
   издания 2012 и не приписывать права ККББ или редактору.
4. Точная цифровая и печатная редакция Синодального перевода и её правовой статус.
   `convert-ru-synodal.py` загружает `thiagobodruk/bible`,
   `convert-ru-scrollmapper.py` — `scrollmapper/Bible_Databases`; оба пишут
   `bible_seed_ru.json.gz`. Наличие конвертеров не доказывает, какой был запущен.
   Происхождение от bible.by не установлено. Live Firestore для проверки не читался.
5. Полные выходные страницы Лекционария, переводчики Кампендыя. Библиографические
   данные из задания помечены `provided_by_request`, а не независимой проверкой.
6. Разрешение на цифровое использование в MyBrev для каждого произведения.
   Наличие ©, общедоступного файла или литургического декрета само по себе его не даёт.

## Перенос во Flutter

1. Копировать `src/data/sources.json` без преобразования в UTF-8 asset, например
   `assets/legal/sources.json`, и объявить asset в `pubspec.yaml`.
2. Читать через `rootBundle.loadString` и `jsonDecode`; проверять `schemaVersion == 1`.
3. Модели должны поддерживать nullable поля, `digitalSources[]`, `verification`,
   `digitalPermission`, `decrees[]`, `legacyAttributions[]`. Сохранять ID между релизами;
   не выводить `null` строкой и не подставлять сайт вместо правообладателя.
4. Для Web используется `bindings.bible[language][testament]`; Flutter должен связать
   **свои реально доступные корпуса** с соответствующими ID, а не предполагать их
   совпадение с Web. Для полного корпуса Чарняўскага выбирать его запись и для NT.
5. В «Пра праграму» отображать все записи, официальное издание, ©, правообладателя,
   перевод и статус проверки. Неизвестное показывать как требующее проверки.
   `digitalSources.status == candidate` не выдавать за подтверждённый источник.
6. Не трактовать `verification.status` как лицензию; разрешение хранится отдельно.
   Для часов показывать три подтверждённых декрета и нерешённый IV том.
7. Валидировать уникальность ID и все `bindings`, перенести проверки из
   `tests/sources.test.mjs`; не требуются Firestore, миграция или публикация контента.

## Проверки

проверка границ PR: `git diff --name-only <base> > /tmp/source-diff.txt`, затем
`SOURCE_AUDIT_DIFF=/tmp/source-diff.txt node tests/sources.test.mjs`.

(по умолчанию `http://127.0.0.1:3000`; `SMOKE_BASE_URL` переопределяет адрес).

320, 390, 1440 px, раскрытые примечания/декреты, клавиатура, внешние ссылки,
