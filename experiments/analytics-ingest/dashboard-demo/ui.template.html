Демо-панель аналитики (локальная, автономная)

Все числа — открытия экранов из детерминированной синтетики (WEB/Android/iOS → обработчик P06 → агрегаты). Людей, устройств и сессий в данных нет, поэтому «сколько пользователей» вычислить нельзя. Не публиковать, не выдавать за статистику. Страница не делает сетевых запросов (CSP connect-src 'none').

Открытия экранов по дням

screen_view; по платформам. Показываются только ячейки «день × платформа × раздел» с n ≥ k; суммы — «не менее».

Открытия по разделам

screen_view, окно хранения

Каталоги (catalog_open)

Открытия экранов-списков. Не двойной счёт с материалами.

Время на экране (fv)

Видимое (foreground) время визита, в корзинах. Короткие визиты <5 с не имеют er/sd.

Приблизительное время чтения (er)

Верхняя оценка по тексту до достигнутой позиции (120 слов/мин, не откалибровано). Не доказательство чтения.

Глубина прокрутки (sd)

fit = текст поместился без прокрутки.

Использование функций (feature_use)

Сколько раз сработала функция (восемь в синтетическом профиле). Без текста поиска и без пути пользователя.

Топ публичных материалов

Только 4 больших каталога, окно хранения, все платформы, топ-10 с n ≥ k. «Хвост» скрыт полностью и не суммируется; идентификаторы публичные (песни — хэши, без названий).

Ошибки измерения

Это про качество измерения, не про ошибки пользователей.
