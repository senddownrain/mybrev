# Локальная база малітваў для імпарту

У гэтай тэчцы захоўваюцца падрыхтаваныя пакеты малітваў. Гэта не рэзервовая копія Firestore і не выканаўчы скрыпт: файлы зручныя для праверкі, дапрацоўкі і паўторнага імпарту.

## Фармат пакета

Кожны JSON-файл змяшчае аб'ект з `schemaVersion`, агульнымі `source` і `prayers`.

Кожны элемент `prayers` адпавядае дакументу калекцыі `prayers` Firestore:

```json
{
  "externalId": "стабільны-ідэнтыфікатар",
  "title": "Назва",
  "text": "Тэкст у MyBrev Markdown",
  "textFormat": "mybrev-markdown",
  "textFormatVersion": 1,
  "tags": ["Катэгорыя"],
  "source": {
    "url": "https://…",
    "attribution": "Крыніца: …"
  },
  "reviewStatus": "ready_for_review"
}
```

`externalId` трэба выкарыстоўваць для выяўлення дублікатаў пры імпарце; у Firestore ён можа застацца полем дакумента або стаць яго ID. Поле `source` варта захоўваць пры імпарце: Catholic.by патрабуе спасылку пры выкарыстанні матэрыялаў.

Тэксты захоўваюцца ў [MyBrev Markdown](../../docs/prayer-markdown.md): назва заўсёды асобна, а не ў першым загалоўку тэксту. Запісы са статусам `ready_for_review` трэба зверыць перад публікацыяй; пасля праверкі змяніць статус на `approved`.

Назва файла: `YYYY-MM-DD-<крыніца>-<раздзел>.json`. Адзін файл — адзін лагічны раздзел або партыя, таму іх можна бяспечна папаўняць і імпартаваць незалежна.
