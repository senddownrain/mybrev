# D-1: выбор конкретного чтения (holy-women и другие поля с отсылкой)

Ветка `feature/d1-reading-choices` (от `origin/main` 2949f66). Draft PR. Ничего не опубликовано: ни Firestore, ни manifest/версия, ни Hosting, ни Flutter. Данные (`patchs/**`) не менялись.

## Что было

В ридере уже есть общий выбор вариантов (`AlternativeText`, вкладки). Для чтений Часа чтений он работал плохо:

| Поле | Что видел пользователь |
|---|---|
| `holy-women.officeOfReadingsR2`, Адвент/Рождество/Пост/Пасха | вкладка «Варыянт 1» с одним предложением-отсылкой («Выбіраюцца найбольш адпаведныя тэксты …, с. N»), потом два чтения; вкладка Хрызастома в Посту/Пасхе называлась «Варыянт 2» |
| `holy-women.officeOfReadingsR1`, все 4 сезона | **одна** вкладка «Варыянт 1»: отсылка и оба чтения для святой в браке склеены в один блок (разделитель «Іншае, пра святую …:» не распознавался) |
| `holy-women.officeOfReadingsR2`, обычное время | вкладка-отсылка + вкладка «Або іншае, пра святую, якая жыла ў сужэнстве» (Пій XII) |
| выбор | не запоминался, сбрасывался только при смене текста |

## Что сделано (только ридер, схема данных не тронута)

1. `src/utils/liturgicalAlternatives.js`: новый вид `office-reading` для чтений Часа чтений.
   - Предложение «Выбіраюцца найбольш адпаведныя тэксты …» распознаётся как **рубрика выбора** (`reference: true`), а не чтение; `getReadingChoices(html)` → `{ notes, options }`.
   - Новые границы выбора: «Або іншае, пра святую …:» и «Іншае, пра святую …:» (только для `office-reading`).
   - Заголовки вкладок: Писание — книга и стих («Кніга Прыпавесцяў Саламона 31, 10-31», «Першае пасланне св. апостала Пятра 3, 1-6. 8-17»); отцы Церкви — произведение и автор (««Гамілія …» св. Яна Хрызастома, біскупа», «Казанне св. Аўгустына, біскупа»); приклеенные «Прыпавесцяў31» разделяются пробелом (только в заголовке вкладки, текст не трогается).
2. `AlternativeText.vue`: отсылка выводится заметкой (`role="note"`) над переключателем и не занимает вкладку; если после отсылки остаётся один текст, переключателя нет (Пій XII в обычном времени); стрелки/Home/End и roving `tabindex` для вкладок.
3. `Lectio.vue` + `useReadingChoice` + `readingChoice.js`: выбор запоминается на сессию (sessionStorage, в try/catch) по ключу «поле + дата + id варианта Часа». Смена дня, периода (дата), Proper↔Common (другой id) и другого поля даёт чтение по умолчанию; запись в другом контексте заменяет запись. Lectionis и Morning передают `field`.

Не затронуто: «Іншыя варыянты дня» (другая сущность), календарь, ранги, Proper, выбор Common по сезону, `assembleOffice`, Flutter.

## Что осталось (решения владельца / отдельные задачи)

1. **Отсылка не раскрыта в базе и в R1.** Том печатает «выбираются тексты из Агульных тэкстаў пра святых мужчын», но в хранилище: R2 I/II содержит чтения `holy-men` (законные, сезонные), а **R1 всех сезонов и R1/R2 тома III** — нет. Пользователю в этих полях показывается только отсылка и женские чтения (и Пій XII). Добавление чтений `holy-men` — это изменение данных (`completeReferenceSets`/`REFERENCE_SET_FIELDS` в `analyze.mjs`, затем импорт holy-women по allowlist), нужно решение владельца и отдельное разрешение на публикацию. Не делалось.
2. Публикация: изменение только в клиентском коде — достаточно WEB-деплоя (`deploy-firebase-hosting.yml`, вручную, после разрешения). Данные и manifest не нужны. Flutter не затронут: у него свой ридер, перенос выбора чтений — отдельное задание.
3. Локальная урачыстасць годовщины посвящения кафедры — backlog §9 ТЗ, не часть D-1.
